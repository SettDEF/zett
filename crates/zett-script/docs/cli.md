# On the command line

    zett                    the editor here (the dashboard)
    zett FILE…              open files
    zett --gui              the notes window
    zett doc [TOPIC]        this documentation
    zett ls / show / new / add / edit    pages, from scripts
    zett run COMMAND        run a command headless
    zett lua CODE           run Lua with the zett API
    zett commands / keys    list them

`zett --help` and `zett COMMAND --help` say more. `--json` makes output
machine-readable.
